# Public Strategy Replication

This directory contains small, reproducible replication studies for public strategy rules.

The goal is not to reuse a public strategy as-is. The goal is to validate:

- local daily data fields and adjustment conventions
- signal timing and anti-lookahead behavior
- backtest engine results against independent calculations
- differences between public reported returns and local implementation assumptions

Each replication should record:

- public source
- rule interpretation
- local data source and adjustment convention
- execution timing
- fees and slippage
- target public result, if available
- local result and difference notes
